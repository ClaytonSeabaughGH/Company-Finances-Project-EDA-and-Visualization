# Company Finances Project

## Overview
This project focuses on cleaning, analyzing, and visualizing financial data to uncover trends and insights that drive informed decision-making. Using **SQL (MySQL)** for data cleaning and analysis, and **Tableau** for visualization, this project demonstrates the ability to transform raw data into actionable insights.

## Key Features
- **Data Cleaning**: Applied SQL to clean financial data, ensuring accuracy and reliability in reporting. Techniques included:
  - Detecting and rectifying inconsistencies.
  - Using **CASE statements** and **aggregate functions** to standardize and enhance data quality.
- **Exploratory Data Analysis (EDA)**: Conducted in-depth analysis to extract valuable insights, such as trends in profit and sales over time.
- **Interactive Dashboard**: Developed a Tableau dashboard featuring a variety of graphs to visualize key financial trends and insights.

## Repository Structure
- **Company Finances Project.twbx**: Tableau workbook containing the interactive dashboard.
- **Company Finances SQL.csv**: Cleaned and processed dataset used for analysis.
- **Data Finances Project.sql**: SQL scripts for data cleaning and transformation.
- **Exploratory Data Analysis Company Finances Project.sql**: SQL scripts for exploratory data analysis.
- **README.md**: Project description and instructions.

## Tools & Technologies
- **SQL (MySQL)**: For data cleaning, transformation, and analysis.
- **Tableau**: For creating interactive visualizations and dashboards.
- **Excel/CSV**: For data storage and initial exploration.
